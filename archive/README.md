# Investigation archive

This holds the device captures, reverse-engineering notes, and superseded
scripts used to identify the PICO-8 cold-data range and mapped-sidecar path.
The current release pipeline lives at the repository root and uses the
maintainer-supplied range in `../gwrg.json`.

Binary images, extracted blobs, ELF files, and ZIP bundles remain available in
the local archive but are ignored by Git because they contain upstream core
code or device memory dumps.
